# Support

## Getting Help

### Documentation

Check the project's `README.md` and any docs folder for guides and API references.

### Issues

Found a bug or want a feature? Open an issue in the relevant repository using the provided issue templates.

### Discussions

Use [GitHub Discussions](https://github.com/orgs/eighty-eighty/discussions) for questions, ideas, and general conversation.

### Security Issues

**Do not** open public issues for security vulnerabilities. See [SECURITY.md](./SECURITY.md) for our disclosure process.

### Commercial Support

For commercial support inquiries, contact [support@8080.li](mailto:support@8080.li).
